# 🏗️ Civil Engineer Portfolio Website

> Built from scratch with HTML, CSS, and JavaScript

A clean, responsive portfolio website for **Alex Rivera, P.E.**, showcasing his civil engineering projects, bio, and contact info.

Perfect for freelancers, engineers, architects, or construction professionals.

## 📂 Features

- ✅ Homepage with hero banner + call-to-action
- ✅ About page with professional bio + photo
- ✅ Projects gallery (responsive grid)
- ✅ Contact page with form + Google Maps + social links
- ✅ Mobile-friendly hamburger menu (with JS toggle)
- ✅ Custom styling with CSS variables
- ✅ No frameworks — vanilla front-end only

---

## 🛠️ How to Use

1. Download or clone this repo
2. Open `index.html` in your browser — no server needed!
3. Replace images, text, and contact info with your own
4. Deploy with GitHub Pages, Netlify, or Vercel

---
